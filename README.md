# Concrete Culture Web

Concrete Culture website concept developed for a Branded Promotions partnership pitch.

## Goals

- E-commerce storefront prototype for paint, supplies, apparel, and limited drops
- Local artist exposure and Wall Rank partnership positioning
- Capsule drop waitlist, sales campaigns, events, workshops, and CC Lab products
- Admin-friendly demo content in `src/data` and centralized config in `src/config`

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

The app is configured for static export to `out/`, making it Vercel-ready and Sites-ready.

## Future Integrations

- Shopify, Stripe, WooCommerce, Medusa, Commerce Layer, or Supabase
- CMS-backed products, artists, events, workshops, and drops
- Mailing list tools such as Mailchimp, Klaviyo, ConvertKit, or Supabase
- Wall Rank API, Instagram, TikTok, YouTube, and event RSVP systems
